# About Ironhack Statistical Test Navigator

Ironhack Statistical Test Navigator is an educational resource designed to help students understand statistical inference through intuitive explanations, visualisations and practical examples.

Its goal is to bridge the gap between statistical theory and practical data analysis by providing a structured learning path through the main concepts of statistical inference.
