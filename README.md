# Ironhack Statistical Test Navigator

Interactive guide for selecting and understanding statistical tests.

## Installation

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run locally

```bash
mkdocs serve
```

Open

http://127.0.0.1:8000

## Build

```bash
mkdocs build
```

## Project structure

```
docs/
mkdocs.yml
requirements.txt
```
